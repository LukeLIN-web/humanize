Deletes sentences that carry no claim while holding every claim constant: bookkeeping counts (「569 → 551」「32 条里的 39」), defensive meta-narration (「这里只报不主张」), journey narration (「起初以为 X，重跑推翻」), restatement and hedge stacking, narrated absences (「X 没有报这一格」), false pivots (「不是 A 而是 B」), value series (一个量在三档以上条件下的读数串成一句), provenance assurance, process vocabulary (「预注册」「冻结后才读」) and the escalation rule: a secondary claim that survives only behind a pile of caveats is deleted. # 文档废话清理(删空句,主张不动)

跑实验的 agent 写文档，会把审计过程写进正文：核过的每个数都印出来，想过的每个范围限制都占一句，排除过的每种读法都交代一遍。每一句单看都站得住，所以从里面看不出漂移。结果是准确但读不下去，结论埋在它自己的来历底下。

这个 skill 只删空句，不定主张。主张还没定（数对不对、能不能这么说）先去定，定完再跑这一遍。

| skill | 问的是 |
|---|---|
| `docs-jargon-pass` | 读者看不看得懂这个词？ |
| `docs-ssot-tighten` | 这个数在别的页是不是又抄了一遍？ |
| **`docs-prose-tighten`** | **这一句删了，读者会不会信错东西？** |

三者正交。jargon-pass 改「看不懂」，ssot-tighten 删「跨页复本」，这里删「页内空句」。

## 唯一的检验

对每一句、句里的每个数问：

> **删掉它，读者的判断会变吗？**

不变就删。不是改软、不是缩短，是删。

数**就是**结论时留；数只证明作者记了账时删。没人靠读段落核数，核数看表。

## 升级规则：caveat 一多就删主张

一句话要一个限定从句才成立，修那句。要两三个，说明这句不值得留，caveat 是诊断而不是病。

> **一个次级主张的诚实版本要堆一串 caveat，就把主张删了。**

只对次级主张（佐证的剂量曲线、「顺带还查了」的子集读数）生效，不对 headline。判法是删了这一页少什么：承重的主张连同它的 caveat 一起留；锦上添花的连 caveat 一起走。user 说「越解释越乱」「别解释了」就是在执行这一条——别用一句措辞更好的解释去回应。

## 十类可删项

1. **记账计数**——中间状态的计数、子集分母、配对拆分，印出来证明做过。「弃权块 569 → 551，所以静音扰动了门但没让它塌」只留「静音扰动了门但没让它塌」。**留**：圈定主张范围的分母（「1062 题里 801 题超长」）、headline 的差值和区间、论证转折处的那个率。
2. **自辩元叙述**——讲自己怎么报数而不是讲系统：「这里只报不主张」「我们不做这个结论」「写出来是因为读者有权知道」。删整句；若它带着真实的范围限制，那个限制缩成主张上的**一个形容词**（「描述性」「事后」）。
3. **走过的弯路**——「起初以为 X……重跑推翻了这点」「没为每条单开一臂，只记了原因」。留结论，删过程。被推翻的那条本身是贡献时（证伪的构造、生效的负对照），给**一句**。过程史归 git 历史和「计划决策落账」节。
4. **复述与套叠的 hedge**——同一个事实在段首、段中、段尾「因此」各说一遍；「与……一致」「我们读作」「在……意义上」叠在本来就带 hedge 的主张上。留一处，放在读者需要的位置。
5. **无中生有**——主语是不存在的东西：「X 没有报这个骨干的行」「这一档没有官方数」。判法：**读者在页面上看得见这个缺口吗？** 格子里是横线、表里少了一行——看得见，留一句短图例（「— = 未公布」）；表里本来就没有这一项——看不见，删。图注最常藏这一类。**留**：缺口本身是主张（「此前没有 benchmark 同时评 X 和 Y」），或协议事实读者默认会以为相反（「测试局没进训练」）。
6. **错误的转折**——先立一个没人提出的读法、否定它、再给结论：「优势也不能归结为压缩丢掉的东西：按……分档，方法在每档都领先」→「方法在每档都领先」。「是 X 而不是 Y」里 Y 是作者自己编的，删「而不是 Y」。句首否定（「最直接的读法正是数据拒绝的那个」）、否定式小标题、问句式小标题 grep 不到，要用眼扫。**让步式范围 hedge**（「X，尽管 Y」）也是这一类：先在本节和邻节 grep Y 的关键名词，已经正面说过就删让步句；哪都没说过就把 Y 作为正面陈述挪进它所属的那句，再删让步句。
7. **页内跨节重复**——两节在不同分辨率上说同一件事。逐句读看不出来，只有段落地图（流程第 1 步）上看得出。定下哪节是这件事的主人（通常是推导它的那节，不是断言它的那节），其余缩成一句主张加指针。第二份里有第一份没有的数、对比或机制时不算重复。跨**页**的数字复本归 `docs-ssot-tighten`。
8. **产物来历的保证**——主语是产物怎么来的：部署的哪个点、怎么挑的、不是按什么挑的、哪段曲线平。这些属于配置表的一个格子或结果页的产物列，不进段落。**留**：读者不知道就会以为是另一个实验的事实——headline 数在哪个集上算、训练/测试分开、分母规则、对比依赖的协议。
9. **流程术语**——「预注册」「判据冻结后才读数」「冻结的余量」「提前停的门」「验收门」。它们是挂在真实结果上的**形容词**，名词承重，所以 2、8 类会放过它们。删修饰语，留名词。**留**技术意义的「冻结」：冻结的骨干、冻结的分词器、冻结的协议——描述不动的权重和配置，不是描述「我们什么时候看的」。
   例外：项目自己的结果页若规定冻结件、预声明时间戳是证据（`docs-ssot-tighten` 硬保护 1、3），那些文件和时间戳不动；这一类只删**散文里**的这种修饰语。
10. **罗列**——一个量在三档以上条件下的读数串成一句：「命中率按四个距离层是 96.7 / 90.0 / 91.3 / 80.8%」。罗列总是为了说明一个**形状**（单调降、持平、某一档掉队），读者只取形状词。写形状词，删数字，指向承载这些数的表或图，最多留论证转折处的**一个**数（上界、被比较的天花板）。**不算**：两个值对比、一个区间、近似相等本身就是主张的一对。

## 硬保护

删字不许升级主张。

- **不许删出一个胜利。** 删掉 null 的标注句时，整句删，不换成「无差别」「不受影响」——那是在断言 null。null 还能带哪些词按项目裁定。
- **不删圈定范围的分母**（全分母规则、限定推广范围的子集大小）。
- **协议差异不许哪都不写**（不同服务栈、剔除失败的分母、不同预算）。保护的是事实不是句子：先按第 6 类查它是否已被正面说过。
- **不删表里、图上、图注里的数。** 这里改散文。段落里挪走的数，正因为表还留着才挪得走。图注本身臃肿另作处理；这里只扫图注里的 5、6、8、9 类。
- **不删引用和链接。**
- **不删「先前的分析读数不同」的披露。** 它长得像第 3 类的弯路叙事，删了等于把不一致的旧读数藏进抽屉。交给 user 定；user 定删时，先核一件事并说出来：**有没有报出的数是在被抹去历史的那个产物上算的？**
- **删「重复」前先核它是重复。** grep 区分性的名词：只此一处的结论不是重复，挪到主人那节而不是删。被挪去的地方回指了原节的，原节留一句。
- **user 原话、裁定原文不改不删**（项目的 `CLAUDE.md` 常规定哪些段只记 user 原话）。协作者手改过的句子跳过并报「这段没动」。

经验法则：**删证明勤奋的，留圈定范围的。**

## HTML 页

- **读读者看到的样子。** 先按 `docs-jargon-pass`「读读者看到的样子」那段抽出页序文本，在文本上建段落地图和清单，再回源码里改。
- **只改人看得到的字**：段落、图注、表格里的短语、SVG `<text>`、`title` / 悬停提示的模板字符串。数字、class、结构、脚本不动。
- **图版页的文字正本在同名 `.md`**：页面上的句子是从 `.md` 抄的，就改 `.md` 再把页面跟上（或者页面那句直接删，留图）。生成出来的页改模板或生成器再重跑，别手改产物。
- 页面规则要求「图多字少」时，第 4、7 类在 HTML 上的结论通常是：图已经画出来的，配文删到只剩一句图注。
- 改完照项目规矩发布（例如 `publish-html`）。

## 流程

1. **先画段落地图，再读文风。** 每段一行：文件、行号、字数、**一句话它主张什么**。md 按空行切段；HTML 在抽出的页序文本上切。从地图里看两样东西：一句话摘要相同的两行 → 第 7 类，最大的删减在这里；超过约 300 字的段 → 它同时在讲几件事，**拆**（第 5 步）。地图先给 user 看，user 挑的比你自己排的值钱。
2. **划范围。** 先正文，后附录、脚注；表和图注只扫 5、6、8、9 类。
3. **建清单**（用 `command grep`：Claude Code 的 `grep` 是带 `--ignore-files` 的 ugrep，递归时会静默跳过 gitignore 的文件）：

   ```bash
   F="docs/*.md"   # 或 HTML 抽出的 .txt
   # 记账形状：「N/M」「N → M」「N 条里 M 条」「N of M」
   command grep -nE '[0-9]+ ?(→|->) ?[0-9]|[0-9]+ ?(条|局|题|个)?里(的)? ?[0-9]|[0-9]+ of [0-9]' $F
   # 罗列：斜线串起的读数
   command grep -nE '[0-9.]+%? ?/ ?[0-9.]+%? ?/ ?[0-9.]+' $F | command grep -v '^\s*|'
   # 自辩元叙述
   command grep -nE '只报不|不(作|做)(这个)?(结论|主张)|有权知道|写出来是因为|以防|并非我们' $F
   # 无中生有
   command grep -nE '没有(报|公布|给出|这一?(格|行|列|档))|未(报告|公布)|无官方' $F
   # 错误的转折（高召回，人工分类；小标题、图注标题要用眼扫）
   command grep -nE '而不是|而非|不是[^。]{1,30}而是|并不是|不能归结|也不是|尽管|虽然' $F
   # 流程术语，逐词计数
   for t in 预注册 预声明 冻结后 冻结前 "读数之前" 提前停 验收门 停止规则; do
     n=$(command grep -c -- "$t" $F 2>/dev/null | awk -F: '{s+=$NF} END{print s+0}'); [ "$n" != 0 ] && echo "$n  $t"
   done
   ```

4. **先分类，不改写。** 每条标删 / 留 / 改写。多数命中应该是**整句或整个从句删掉**，别把臃肿的句子改成稍微不那么臃肿的句子。主张已定的文档里多数命中是该留的（实测无中生有类约八成是承重的协议范围）——删得少说明检验在起作用。
5. **动手。** 删从句优于重组句子：挪动的字越少，主张走样的机会越小。唯一值得做的重组是第 1 步标出的**拆段**：找出长段里的几个结论，各给一段、各有主题句，拆的同时删。
6. **核主张集不变。** 每个改过的段写一行：改前主张什么、改后主张什么，有差别就是 bug。逐条重过硬保护。删掉的段若是某个锚点或指针唯一的引用者，查一遍有没有悬空。
7. **汇报**：改了哪些文件；按类（1–10）删了什么；**留了什么、为什么留**——留的清单是这次没变成过度主张的证据。不拿「删了百分之几」当标题；标题是这页能一口气读下去了。

按地图定的删减目标通常会高估约一倍：承重段是被**压缩**而不是删掉，「删这一节」多半变成「挪一句、删其余」。照实说，别为凑数多删。

## 反模式

同一段文字别跑两遍指望更多收获。第二遍找不到安全可删的东西，就会开始吃范围限定词来证明自己有用。跑一遍就停。

例外是**只查第 7 类**的一遍：改写过某节以后，重画段落地图、对比一句话摘要，别的不查。
